Four histograms are 1.10× faster than eight for intensity and 1.11× with errors in the cleaner one-thread comparison. Eight-thread intensity is essentially tied within measurement variability. Sixteen histograms are consistently slower, especially with errors. Keep four as the default here; this is not a universal hardware-independent optimum.

Independent histograms break dependent updates to nearby bins. Beyond that benefit, additional histograms increase the hot working set, initialization and reduction costs. These measurements do not contain hardware counters attributing the slowdown to a specific cache level.

Protocol

  • data: Same 16 Eiger9M float64 frames, original float64 full-pixel-split weights,2000bins, solid-angle and polarization0.965, same static mask plus changing threshold230 mask.
  • controls: Only the number of CSC histograms varies:1,2,4,8,16. All pixels, weights, corrections, accumulators and outputs float64; round-trip transpose checks coefficient bits. Same masks reconstructed for each timed frame; normalization and Poisson variance recomputed inside every traversal.
  • timing: Five warmed blocks >=1s per lane/error/thread configuration; rotate/reverse order, warm one full16-frame batch before each block. Includes mask generation/copy, histogram allocation/zeroing, pairwise reduction, normalized output/axes and cleanup.1 and8threads process frames in parallel. No IO, decoding or initial table transpose timed.
  • precision: Every output checked against strict original CSR using exactly the same mask and inputs. Only summation order changes.
  • limits: Eight-thread host activity and worker scheduling caused broad variability; all samples retained. One-thread comparisons are cleaner. No CPU cache counters measured; larger histogram footprint is a plausible cost, not a measured attribution.
  • histograms: Intensity has one signal and one denominator array per lane (4lanes=128000bytes,8=256000). Poisson adds variance (4lanes=192000,8=384000). Array payloads exclude output axes and CSC table.
